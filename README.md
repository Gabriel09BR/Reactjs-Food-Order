# 🌯 WrapHouse – Restaurant Web App

A modern and responsive dummy restaurant website built with React.
The project simulates an online ordering interface for a fictional wrap house, including categorized menus and dynamic filtering.

---

## 🚀 Features

- Category-based menu navigation (Wraps, Drinks, Desserts)
- Subcategory filtering (Coffee, Alcoholic Drinks, Cocktails)
- Dynamic state management with React hooks
- Responsive UI layout
- Clean and reusable component structure

---

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- CSS Modules
- Node.js / npm
